# Pretendard

공식 v1.3.9 글꼴 파일을 수정 없이 사용합니다.

- 웹과 브라우저 인쇄: `PretendardVariable.woff2` (가변 굵기)
- 다운로드 PDF: `Pretendard-Regular.ttf` (400), `Pretendard-Medium.ttf` (500), `Pretendard-Bold.ttf` (700)

웹폰트는 사이트에서 직접 제공하고, PDF용 TTF는 빌드 시 문서에 포함합니다.

출처: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist
