# Astro 이력서 프로젝트

콘텐츠·표시 설정·테마를 UI와 분리하는 정적 이력서 프로젝트입니다.

현재는 **1단계: 하네스 정리 완료, 검토 대기**입니다. 앱·패키지 설정·테스트 코드는 아직 없습니다.
다음 작업은 별도 요청에 따른 **2단계: Astro·Tailwind·Biome·Vitest 개발 환경 구성**입니다.

- [에이전트 작업 지침과 공통 스킬](AGENTS.md)
- [제품 설계](docs/development.md)
- [제품 검증 기준](docs/verification.md)
